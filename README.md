# Hospitality Dashboard (White Label)

This folder is a clean, deployable dashboard package for Vercel.

## Deploy on Vercel

- Import this repository into Vercel
- Set **Root Directory** to `hospitality-dashboard`
- Keep Build Command as `npm run build`

## Branding

Configure these environment variables:

- `NEXT_PUBLIC_BRAND_NAME` (for example: `Your Property`)
- `NEXT_PUBLIC_BRAND_TAGLINE` (optional, for example: `Guest operations`)

## Goal

Run the hospitality operation from one dashboard:

- Reservations and calendar
- Guest CRM and reminders
- Messaging and scheduling
- Concierge content and operations settings
